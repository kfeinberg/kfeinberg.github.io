Word Catcher.

August 6, 2018

  • HTML
  • CSS
  • JavaScript
  • Chrome extension

Keep the words you discover.

I created this project alongside my students in the Girls Who Code Summer Immersion Program. Their idea was a Chrome extension dictionary that could save words, so users could refer back to them later.

This was the first time I had to teach myself a technology I hadn’t learned in school. Although we didn’t end up publishing the extension, we had a great time working on it and learned a lot about web development.
