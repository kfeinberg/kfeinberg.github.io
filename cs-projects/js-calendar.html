October 22, 2018

  • JavaScript
  • PHP
  • AJAX
  • AWS
  • jQuery
  • Bootstrap

Overview

I co-created this project in my Rapid Prototype Development and Creative Programming course, using an existing HTML template, Bootstrap for styling, PHP for security and database interaction, and vanilla JavaScript for functionality.

The calendar supports adding an event with a title, date, and time; editing and deleting events; sharing events with other users; and filtering to show only high-priority events.

AJAX handles requests so updates appear without page refreshes. The original project used salted and hashed passwords and included protections against SQL injection, CSRF, and XSS.

This is an archived student project, not a currently maintained calendar service.
